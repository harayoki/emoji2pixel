emoji2pixel JavaScript API

この資料はアプリに内蔵されています。元のアプリの開発者ツールで window.EmojiPixelAPI を使ってください。この説明ページにはアプリ本体のAPIはありません。画面操作APIはURLのハッシュと画面表示にも反映されます。

まず使う

const api = window.EmojiPixelAPI;
await api.setOptions({preset:'nes', size:32, trim:true, symmetry:'normal'});
api.select('🐱🐶');
api.setTab('選択済み');
api.search('');
await api.download(api.getSelected().join(''), {format:'zip'});

AI向け：APIのJSDoc一覧

api.getAPIInfo() は全公開メソッドの {name, summary, jsdoc} 配列を返します。api.getAPIInfo('setOptions') で1メソッドだけ取得できます。見つからない場合は null。ページの公開APIのJSDocからビルド時に生成します。

const api = window.EmojiPixelAPI;
console.log(JSON.stringify(api.getAPIInfo(), null, 2));
console.log(api.getAPIInfo('select'));
await navigator.clipboard.writeText(JSON.stringify(api.getAPIInfo(), null, 2));

絵文字一覧とフォント

呼び出し動作
api.select(text, {append:false})絵文字を選択。空文字で解除。未登録文字は「入力文字」に追加。append:true は現在の選択に追加。同じ文字は重複しません。最大256文字。
api.getSelected()現在の選択文字を配列で返す。
api.getTabs()タブ名の配列。入力文字が存在すると「入力文字」も表示。
api.setTab(name)タブを切り替え。例：「動物・自然」「顔・感情」「選択済み」「すべて」。英語の別名も使える：all / selected / faces（emotions）/ people（body）/ nature（animals）/ food（drink）/ places（travel）/ objects（symbols）/ custom（text）。
api.search(query)検索欄を変更。日本語、英語、別名、絵文字を検索。空文字で解除。
await api.setFont(mode)system（システム絵文字）、free（Noto Emoji）、color（Noto Color Emoji）、local（読み込み済みフォント）。外部フォントは読み込み完了後に解決。通信エラー時には拒否。
await api.loadFont(file)File または Blob のローカルフォントを読み込み、選択。ブラウザーのファイル選択ダイアログは開かない。
api.select('🐍🦊');
api.setTab('動物・自然');
api.search('snake'); // 英語名でも絞り込めます
await api.setFont('system');
// ファイルを持っている場合: await api.loadFont(file);

画面の設定

await api.setOptions({...}) は画面の設定を変更し、絵文字一覧を描き直します。api.getOptions() は編集可能な設定と選択状態を返します。api.getSettings() は実際に描画へ渡す設定を返します。指定しなかった項目はそのままです。プリセットを指定した場合は先にプリセット値を適用し、その後に同じ呼び出し内の他の指定を適用します。

await api.setOptions({
  size:32, background:'custom', backgroundColor:'#243142',
  trim:true, gapX:1, gapY:2,
  symmetry:'strict', ditherPattern:'bayer2', ditherRange:25,
  gammaMode:'rgb', gammaR:0.9, gammaG:1.0, gammaB:1.1,
  contrast:2, hue:10, saturation:110,
  layout:'grid', columns:16
});
console.log(api.getOptions());

全オプション

キー値・単位
presetnes, micro, msx-sprite, msx-bg, msx2-sprite, msx2-bg, mono2/3/4/8/16, free27/64/125/216/343/512。変更時はプリセットの色・ガンマ・コントラストなどを更新。
nesPattern, microPatternファミコンの配色キー（一覧は NESPalettes.presets.map(p => [p.key,p.name])）、マイコン配色 digital / digital4_1〜digital4_5。
msxPattern, monoPattern, freePatternMSXは msx / msx2、モノクロは mono2/3/4/8/16、フリーは free27/64/125/216/343/512。現在の機種と一致する場合は色パレットを更新。
size, wide1〜128の整数 px、横2倍の真偽値。横2倍の設定は機種により無効。
trim透明な外周の詰め具合。'off'／'small'／'medium'（既定）／'large'。真偽値も受け、trueは中、falseはなし。
oddCenter真偽値。右端・下端を1ドット捨てて、中心をちょうど1ドットにする。
alphaThreshold0〜255の整数。元の絵文字のアルファがこの値より小さい画素を透明にする（既定46）。
scaleX, scaleY元の絵の拡大・縮小 25〜400（%）。中心はそのまま。
gradBrightness, gradHue, gradBrightnessFlip, gradHueFlip上下グラデを効き具合のマスクにした明るさ（輝度）-100〜100（%）と色相 -180〜180（度）。上端で0、下端で最大。Flip を true にすると上下が入れ替わる。
lineKeep, lineRadius, lineThreshold細い線を残す off / dark / both。線とみなす太さ 1〜8、拾いやすさ 0〜255。
offsetX, offsetY元の絵をドット単位でずらす -64〜64。拡大・回転のあとにかかる。
rotate, shearX, shearY元の絵の回転 -180〜180（度）と、横・縦のシアー -60〜60（度）。拡大・縮小の後にかかる。傾けている間は自動左右対称を止める。
trim, symmetry, symmetryBand透明な外周を詰める off / small / medium / large。左右対称の感度 off / strict / normal / lenient。判定の単位は 8（縦8ドットごと・既定）か 0（絵全体）。
gapX, gapY文字内側の左右／上下余白 0〜64 px。0で無効。
background, backgroundColor一覧の背景 default / black / white / grid / custom。customのHEX色は backgroundColor:'#RRGGBB'。MSX BG の出力背景は msxBg を使用。
msxBg, msxVirtualBg, transparentInPaletteMSX BG の背景色（MSXの選択肢か custom）、MSXスプライトの仮想背景色（選択肢のHEX）、仮想背景色に透明を割り当てる真偽値。
ditherPattern, ditherRangenone / bayer2 / lineH / lineV / floyd / jjn / stucki / atkinson / blue16。範囲は5〜100の整数（％）。ditherSpread は0〜100の整数（％）で、色の境目からディザを敷く広がり（既定100＝全面、0＝敷かない）。MSX BGは none / lineH のみ。
gammaMode, gamma, gammaR, gammaG, gammaBall または rgb、ガンマ値は0.25〜3。all なら gamma、rgb なら各成分を使用。
contrast, hue, saturationコントラスト0.25〜3、色相 -180〜180 度、彩度0〜200 パーセント。
count, palette, paletteOff最大色数 1〜512（フリーは任意数、他機種は画面の選択肢に従う）。palette は HEX の文字列またはHEX配列、paletteOff は0から始まる色番号の配列。MSXのパレット色のON/OFFにも対応。
basicPalette, ditherOff追加色の選択元 custom / digital / msx / msx2 / nes52 / rgb27 / rgb64 / rgb125 / rgb216 / rgb343 / rgb512。ditherOff はディザで使わないHEX色の配列。パレットの色そのものは消さない。
rule, lineBg, nesMatch, msxMatchfree / line、背景色をライン内で使用する真偽値、ファミコン luminance / oklab、MSX rgb / oklab。機種ごとの描画制約は自動適用。
layout, columnsgrid / row / column / square。横の個数は1〜256の整数。行は必要なだけ下へ足す。
tileScale, language一覧倍率 auto / 0.5 / 1 / 2 / 3 / 4 / 5 / 6 / 7 / 8。名前表示 ja / en。
saveFormat, codeFormat, base64, codeScope保存形式 png / zip、AS CODE形式 js / python / json / text、Base64の真偽値、プレビュー one / all。
tab, search, selected, fontMode一度の setOptions でタブ、検索文字列、選択文字列、フォントモードも設定可能。fontMode の外部フォントロードも待機。

getOptions() が返す現在の値は編集フォームに相当します。MSX BGのように機種側で強制される設定は getSettings() で有効値を確認してください。不明な項目や無効な値はエラーになります。

まとめて作る

// 感度×詰め具合の総当たりを1回で作り、左右一致率で並べる
const grid = [];
for (const symmetry of ['off','normal','lenient'])
  for (const trim of ['off','small','medium','large'])
    grid.push({symmetry, trim});

const out = api.renderVariants('🐱', {preset:'nes', size:16}, grid, {format:'png', sheet:true, columns:4});
out.variants
  .map((v, i) => ({i, ...v.options, ...v.metrics}))
  .sort((a, b) => b.mirrorMatch - a.mirrorMatch);

設定の下調べ

呼び出し返り値
api.describeOptions()設定できる項目の一覧。各項目に type（boolean / integer / number / enum / color / string / array）、現在値 value、選択式なら choices、数値なら min・max、そして今のプリセットで使えるかを示す available が付く。実装が変わっても、その時点で指定できる項目がそのまま返る。
api.listChoices(name?)選択式の項目の許容値。名前を省くと選択式の全項目をまとめて返す。listChoices('preset') は msx2-bg・mono4 のような実際に指定できるプリセット名を返す。
await api.waitIdle({timeout})一覧の描画とフォント読み込みが終わるまで待つ。終われば true、時間切れなら false。設定変更のあとに固定時間の待ちを入れる必要がなくなる。
api.snapshot()今の画面の要約。プリセット・サイズ・タブ・検索語・フォントの状態・選択中の文字・一覧の件数・字形なしで隠した数・描画中かどうか・拡大表示の有無。
// 今のモードで指定できる項目だけを拾う
const usable = Object.entries(api.describeOptions())
  .filter(([, item]) => item.available)
  .map(([key, item]) => key);

await api.setOptions({preset:'msx-bg', msxBg:'#3eb849'});
await api.waitIdle();
api.snapshot();

変換と保存

呼び出し返り値
api.render(text, options?)スプライトシートを描いた Canvas。
api.renderTile(char, options?)1文字ぶんの Canvas。metadata に自動左右対称の適用有無・判定値・対称軸のずれが付く。
api.renderVariants(char, base?, variants, options?)同じ文字を設定違いでまとめて描く。画面には触れず、再描画も待たないので、総当たりが1回の呼び出しで終わる。各結果に metrics（使用色数・不透明画素数・描画率・左右一致率・対称の判定値）が付く。format は canvas（既定）／png／code、sheet:true で全部を1枚の Canvas にも並べる。
api.toCode(text, options?)AS CODE文字列。format: js / python / json / text、base64:true も指定可能。
await api.download(text, options?)PNGまたはZIPを保存し、ファイル名を返す。format:'png' | 'zip'、filenameで保存名を指定。

一回限りの options に preset を渡すと、その機種の色数・パレット・色の制約も一緒に切り替わります（画面の設定は変えません）。palette や count を同時に渡せば、そちらが優先されます。

これらの options は一回限りの描画設定です。size、count、palette、symmetry、trim、layout、columns などを指定でき、画面状態は変更しません。画面側を変更するには setOptions を使います。文字列は1〜256文字、サイズは1〜128pxです。

const canvas = api.render('😀👾', {size:16, layout:'row'});
console.log(canvas.width, canvas.height);
const source = api.toCode('😀👾', {format:'python', base64:true});
await navigator.clipboard.writeText(source); // AIへ渡すコードをコピー
await api.download('😀👾', {format:'zip', filename:'my-sprites.zip'});

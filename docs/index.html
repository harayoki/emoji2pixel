変換設定

フォントを選択してください。ファイルは端末内で処理します。
元の絵文字が左右対称に近いときだけ、変換後の画素を左右対称にします。縦8ドットごとなら、頭だけ非対称といった絵でも揃う部分だけ揃えます。対称軸は絵全体で1本に決めます。
元の絵の拡大・回転

中心をそのままに、元の絵文字を縦横それぞれ伸び縮みさせ、そのあとで傾けます。縦だけ伸ばして縦長にするといった使い方ができます。100%を超えるとタイルからはみ出した部分は切れます。

位置はドット単位の平行移動で、拡大・回転のあとにかかります。自動左右対称が働いた絵では、中心をそろえる働きと打ち消し合うので横のずらしは効きません。

回転・シアー中は、自動左右対称と「中心を1ドットにする」を止めます。

元の絵文字のアルファがこの値より小さい画素を透明にします。0ですべての画素を描きます。
色の調整

ドット絵にする前の絵文字そのものへ効きます。減色のしかたが変わるので、つぶれがちな細部を出したり、逆に整理したりできます。

ガンマ・コントラスト・色相・彩度が元の色の出かたを決めます。

「着色」は指定した色を混ぜます。混ぜ方はフォトショップの描画モードと同じで、「ノーマル」は指定色へそのまま寄せ（100%で塗りつぶし）、「乗算」は暗く、「加算」「スクリーン」は明るく寄ります。既定の「輝度維持」は、単色の絵文字に色を付けても輪郭や陰影が残る混ぜ方です。透けている画素ほど効果は弱くなります。かける位置を「色の調整の前」にすると、単色の字形を塗ってから色相や上下グラデで色味を動かせます。「後」だと白のまま色味を動かすので、グラデは残りません。

上下グラデは、上端で0・下端で1になる縦のグラデーションを効き具合のマスクにして、明るさ（輝度）と色相をずらします。上下反転を入れると、上端で最大・下端で0になります。単色の絵文字に色味の変化を出したり、逆にきついグラデーションを打ち消したりできます。

縁取り・影

元の絵の字形そのものを加工します。減色の前にかかるので、足した色もパレット選びの対象になります。

縁取りは字形のまわりを指定色で太らせます。4方向は角を落とし、8方向は角も埋めます。字形がタイルいっぱいのときは縁がはみ出して切れるので、「元の絵の拡大・回転」で少し縮めてください。

影は半透明を使わず、縁取りまで含めた影絵を指定ドット数ずらして指定色のベタで敷きます。角度は上を0度とした時計回りで、90度が右、135度が右下です。

それぞれの「かける位置」は、ガンマ・コントラスト・色相・彩度・着色・上下グラデの前に挿すか後に挿すかです。前にすると指定した色もそれらの調整を受けます。

JavaScript API MCPサーバーの代わりに
このHTMLツールには、ブラウザーのデバッグコンソールから呼び出せるAPIがあります。ブラウザーを操作できるAIコーディングツールにこのページを表示すれば、AIエージェントがAPIを実行できます。別のMCPサーバーを立てずに変換を自動化できます。

const api = window.EmojiPixelAPI;
await api.setOptions({size:32, trim:true, symmetry:"normal"});
api.select("🐱🐶");
api.setTab("選択済み");
api.getSettings(); // 現在の設定を確認
const canvas = api.render('😀👾', {size:32, layout:'row'}); // Canvasに変換
api.toCode('😀👾', {format:'json', base64:false}); // コードを取得
await api.download('😀👾', {format:'png', size:32}); // PNGを保存
await api.download('🐱🐶', {format:'zip'}); // ZIPを保存
